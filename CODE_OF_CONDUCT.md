# Code of conduct

This project welcomes contributors of all backgrounds and experience levels. Treat people with respect in issues, pull requests, reviews, and other spaces maintained for this repository.

## Expected behavior

- Discuss the work with specific, constructive feedback.
- Respect different experiences and levels of technical knowledge.
- Accept corrections and take responsibility for mistakes.
- Credit other people's work and disclose relevant affiliations.
- Respect privacy and requests to stop an interaction.

## Unacceptable behavior

Harassment, discriminatory language, threats, personal attacks, sexualized behavior, repeated unwanted contact, and publishing private information without consent are unacceptable. Spam and repeated disruption are also grounds for moderation.

## Reporting

For a conduct concern involving this repository, use a private contact method that the owner makes available on their [GitHub profile](https://github.com/adamwhitlock1). If no suitable private route is available, use GitHub's **Report content** option on the offending content or profile. Do not post sensitive personal information in a public issue. GitHub reports are handled by GitHub and may not be shared with the repository owner.

## Enforcement

The repository owner is responsible for moderation here and may edit or remove content, warn a participant, limit participation, or block an account according to the severity and pattern of behavior. Reports should be handled discreetly, and retaliation against a reporter is prohibited.

This policy applies to participation in this repository and to public spaces where someone explicitly represents this project. It does not govern the independent projects linked in the list.
